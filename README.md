# MusicPlayer

아이폰 파일 앱의 음악을 기기에 저장해 오프라인으로 듣는 개인 PWA 음악 플레이어입니다.

## v1.0.0

- 여러 음악 파일 가져오기
- IndexedDB에 원본 오디오 Blob 저장
- 오프라인 재생
- 이전/다음, 셔플, 반복
- 마지막 곡과 재생 위치 기억
- Media Session API 기반 잠금화면 재생 컨트롤
- 저장 공간 확인 및 전체 삭제

## iPhone 테스트

1. GitHub Pages 주소를 Safari에서 연다.
2. 공유 → 홈 화면에 추가.
3. 음악 파일을 가져오고 직접 재생을 시작한다.
4. 홈으로 나가기 / 다른 앱 전환 / 화면 잠금을 각각 테스트한다.

iOS는 웹앱 프로세스를 임의로 중단할 수 있으므로 백그라운드 재생은 네이티브 앱만큼 보장되지 않습니다. 음악 파일은 GitHub로 업로드되지 않고 브라우저의 IndexedDB에 저장됩니다.
